Configurar Google Login (redirect_uri_mismatch)

O backend já está certo. Cadastre a URL abaixo no Google Cloud.

1. Copie esta URL:

http://localhost:3001/api/auth/google/callback

2. Abra as credenciais no Google:

Abrir Google Cloud → Credenciais

3. No Google Cloud:

  1. Clique no seu cliente OAuth 2.0 (o que você usa no app).
  2. O tipo tem que ser Aplicativo da Web. Se for "Aplicativo para computador", crie um novo cliente do tipo "Aplicativo da Web" e use o novo ID/secret no .env.
  3. Em URIs de redirecionamento autorizados → + ADICIONAR URI.
  4. Cole a URL que você copiou (Ctrl+V) e salve.
